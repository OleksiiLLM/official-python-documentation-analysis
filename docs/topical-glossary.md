# Topical Glossary

**_Encoding_**: Is the process of converting data (like letters, numbers, and emojis) into binary data (1s and 0s) that computer can efficiently store.

**_Decoding_**: Is the process of converting data fron an encoded format back to its original form.

**_Source Character_**: Is the individual, human-readable text symbols (letters, numbers, spaces, punctuations, and emojis) that the Python engine extracts from Python extension file.
