# Formal Language

In the context of Python (and computer science in general), a **Formal Language** is a language designed by humans for a very specific, technical purpose - with absolute, mathematically precise rules. Programming languages, including Python, are formal languages.

Think of it as the exact opposite of a "Natural Language" (like English or Japanese). Natural languages evolve organically; they are full of slang, idioms, metaphors, and ambiguity (for example, the word "read" can mean two different things depending on the context). A formal language has zero ambiguity. If a sentence (a line of code) is valid, it means exactly one thing, every single time.

Ultimately, a formal language sacrifices the poetic flexibility of human speech in order to gain the 100% precise, unambiguous instructions required for a computer processor to execute tasks.
