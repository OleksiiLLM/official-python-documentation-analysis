# Libraries

In Python, a **Library** is a broad catch-all term for any collection of pre-written code that you can import into your project to solve a problem without having to write the solution from scratch.

Think of a library as a massive toolbox. If you need to drive a nail, you do not forge your own hammer; you just open the toolbox, grab a hammer, and use it.

* **How it works:** A general library can contain simple variables, standalone functions, or complex objects. It doesn't force you into a specific style of programming.

* **The Standard Library:** Python is famous for its "batteries included" philosophy, meaning it ships with a massive built-in library. You can import tools like _math_, _json_, or _csv_ immediately.

* **Everyday Example:** When you use _import math_ and _call _math.sqrt(16)_, you are using a standard library. It just gives you a standalone function that calculates the square root.
