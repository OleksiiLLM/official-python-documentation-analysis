# Reference Manual
***
In the context of Python, a **_Reference Manual_** is the official, exhaustive rulebook for the language.
***
It is designed to be terse, exact, and complete - meaning it prioritizes strict technical accuracy over beginner-friendly tutorial.

Think of it like a dictionary or an encyclopedia rather than a textbook. You do not read it from cover to cover; you open it when you know exactly what you are looking for and need to see the precise rulus of how it behaves under the hood.

**Python splits its official documentation into two primary reference manuals**

* **The Python Language Reference:** This document describes the exact syntax and core semantics of Python (the fundamental rules of how the language is structured and executed).

* **The Standard Library:** This manual describes all the built-in modules, data types, and functions that come pre-packaged with Python out of the box.

Ultimately, a reference manual tells you exactly what a feature does and its technical parameters.
