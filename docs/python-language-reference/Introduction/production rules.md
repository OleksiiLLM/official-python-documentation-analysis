# Production Rules

In the context of Python (and computer science as a whole), **Production Rules** are the individual, specific mathematical formulas that make up the language's overall Grammar Definition.

They literally dictate how smaller pieces of text can legally "produce" a larger, valid piece of code.

Think of it like a single recipe in a massive cookbook. If the entire cookbook is the Grammar Definition, a single production rule is just the specific recipe for making a sandwich:

    Sandwich = Bread + Meat + Bread.
