# Semantics

In the context of programming languages and natural languages (human languages), **_semantics_** refers to the strict logic of a sentence.

Semantics is about the message in the sentence.

For example, a sentence from a natural language: "The invisible pink unicorn ate a loud concept." 

Structure of the sentence and spelling of the words, are correct. But meaning of the sentence is complete nonsense.

Ultimatly, sementics is responsible for meaning (logic) of a sentence.
