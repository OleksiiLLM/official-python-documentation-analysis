# Omitted

In the context of Python, to say something is Omitted simply means to intentionally leave out an optional piece of code—usually a function argument or a slicing index—because it is not strictly required for the code to run.

Think of it like ordering a coffee. If you ask for an "iced coffee" and omit specifying the type of milk, the barista doesn't crash and refuse to serve you; they just fall back to their default recipe (like regular whole milk).
