# Class Libraries

A **Class Library** is a specific type of library where the code is built almost entirely around Object-Oriente Programming (OOP). Instead of just handling you standalone functions to run, a class library hands you **Classes** - blueprints for creating complex objects that manage their own state and behavior.

Think of a class library less like a toolbox of simple hand tools, and more like a catalog of specialized factory machines. You don't just "use" the machine; you instantiate it, configure its settings, and interact with its specific control panels.

* **How it works:**To use these libraries, you typically have to create an instance of a class (an object) or inherit from their classes to build your own custom versions.

* **Everyday Example:**Graphical User Interface (GUI) libraries like _tkinter_ or _PyQt_ are heavily class-based. You don't just call a function to make a window appear. You instantiate a _Window_ class, create instances of _Button_ classes, and attach them to the window object.

* **Another Example:**The _datetime_ module in Python. You don't just call a generic time function; you create a specific _datetime_ object that holds the year, month, and day, and that object has its own specialized methods.
